title: Voice
---

Every rule ships on, so this file turns nothing off. It is here for the prose
below, which is what a rule set is mostly for.

Write the way you talk to someone who already knows the subject. Say the thing,
then say why it matters. If a sentence needs three commas to survive, it is two
sentences.

Never open with throat clearing. The reader arrived on purpose.

A rule set sits in the directory it governs, so this one covers the whole vault
and `drafts/voice.md` covers the drafts. The nearest file wins, and a document's
own `voice:` frontmatter wins over both.
